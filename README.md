# ClipBoost Automation — بوت تلغرام لتجهيز مقاطع Content Rewards

## الفكرة (النسخة النهائية المبسّطة)

بدل النشر التلقائي المباشر على TikTok/YouTube/Instagram (اللي يحتاج تسجيل تطبيقات ومراجعات معقدة)،
المشروع الآن بوت تلغرام بسيط يشتغل بقناتك الخاصة:

```
أنت (بتلغرام) → ترسل فيديو/رابط + شروط الحملة
                          ↓
                    البوت يقص + يحوّل 9:16 + يضيف Hook
                          ↓
              يرجّع لك الفيديو جاهز بنفس القناة
                          ↓
        أنت تنزّله وتنشره يدويًا على المنصات (TikTok/YouTube/IG)
```

لا حاجة لـ OAuth، لا Redirect URI، لا مراجعة تطبيقات. بس توكن تلغرام بسيط.

## الملفات

- `bot.py` — البوت نفسه (يستقبل الرسائل، يفهم الشروط، يرسل الناتج)
- `video_processor.py` — معالجة الفيديو (قص، تحويل مقاس، إضافة Hook)
- `requirements.txt` — المكتبات المطلوبة

## طريقة الاستخدام داخل تلغرام

أرسل للبوت فيديو (أو رابط) مع رسالة/كابشن بهذا الشكل:

```
رابط: https://... (اختياري إذا رفعت فيديو مباشرة)
هوك: النص اللي يطلع أول الفيديو
وصف: وصف الفيديو
هاشتاغ: #tag1 #tag2 #tag3
مدة: 30
```

البوت يرجّع لك فيديو جاهز (9:16 + Hook) مع كابشن فيه الوصف والهاشتاغات جاهزة للنسخ.

## التشغيل

راجع تعليمات التشغيل الكاملة من الجوال (عبر Replit) — بدون كمبيوتر، بدون تثبيت محلي.

الخطوات المختصرة:
1. خذ توكن من **@BotFather** بتلغرام (`/newbot`)
2. سوّي مشروع Python على **replit.com** وارفع هالملفات الثلاثة
3. حط التوكن بـ **Secrets** باسم `TELEGRAM_BOT_TOKEN`
4. ثبّت المكتبات: `pip install -r requirements.txt`
5. اضغط **Run**

## ملاحظة عن استخراج الفيديوهات من رابط

`bot.py` يستخدم مكتبة `yt-dlp` لتحميل فيديو من رابط عام. استخدمها فقط لمحتوى تملك حقوقه
أو مسموح استخدامه ضمن شروط حملة Content Rewards التي تشارك بها، والتزم بشروط
استخدام كل منصة (YouTube, TikTok...) بخصوص تحميل المحتوى.
